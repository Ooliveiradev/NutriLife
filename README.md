# 🌱 NutriLife

Uma plataforma completa para auxiliar na jornada de saúde e nutrição, oferecendo ferramentas práticas e conteúdo educativo.

## ✨ Funcionalidades

- **📊 Calculadora de IMC** - Calcule seu Índice de Massa Corporal
- **🔥 Calculadora de Calorias** - Acompanhe sua ingestão calórica
- **📚 Banco de Receitas** - Receitas nutritivas e saudáveis
- **📝 Diário Alimentar** - Registre suas refeições
- **📖 Blog** - Conteúdo sobre nutrição e hábitos saudáveis
- **📞 Contato & Suporte** - Formulário para dúvidas e feedback

## 🚀 Tecnologias

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Firebase (Firestore, Authentication)
- **Ícones**: FontAwesome
- **Hospedagem**: GitHub Pages

## 🔧 Configuração

1. Clone o repositório
2. Configure o Firebase no arquivo `js/firebase-config.js`
3. Adicione os UIDs de administradores em `window.NUTRILIFE_ADMIN_UIDS`
4. Abra `index.html` no navegador

## 🌐 Deploy

O projeto está configurado para funcionar perfeitamente no GitHub Pages. Basta fazer push para o repositório e ativar o GitHub Pages nas configurações.
